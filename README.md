# Pygame Car Shooting Game

A Python and Pygame game where the player drives a car through traffic, dodges other cars, and shoots them using a ball to earn points.

## Technologies

- Python
- Pygame

## Features

- Player car movement
- Traffic dodging
- Shooting other cars
- Multiple cars on the road
- Collision detection
- Score system
- Game Over system
- Moving road background
- Timer
- Sound effects
- Background music

## Controls

- Left Arrow: Move the car left
- Right Arrow: Move the car right
- Space: Shoot

- Working with the Pygame game loop
- Handling keyboard input
- Collision detection
- Managing game objects and their movement
- Working with sounds and background music
- Implementing a scoring system
- Managing Game Over state
